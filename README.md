# Rural Cravings

Rural Cravings is a comprehensive e-commerce food delivery platform designed to bridge the gap between authentic traditional flavors and modern convenience. This project features a full-stack web application, a customer-focused mobile application, and a dedicated delivery partner app.

Features: 
Admin Panel: A centralized dashboard to manage food items, categories, orders, customers, and business analytics. 
Website Frontend: A responsive, user-friendly interface for browsing categories, exploring "Best Sellers," and managing orders. 
Customer App: A native mobile experience for ordering food, tracking delivery status, and applying discount coupons. 
Delivery App: A specialized mobile interface for delivery partners to manage and update delivery statuses in real-time. 

Tech Stack:
Web & Admin Panel
Frontend: React, Vite, Tailwind CSS, Mantine UI, Recharts (for analytics).
Backend: Node.js, Express.js, MongoDB, Mongoose.
Authentication & Security: JSON Web Tokens (JWT), Bcrypt, Cookie-parser.
Utilities: Axios, Redux Toolkit, Multer, Cloudinary, Razorpay.

Mobile Apps (Customer & Delivery)
Framework: React Native with Expo.
Navigation: React Navigation (Native, Stack, Bottom Tabs).
State Management: Redux Toolkit.
Networking: Axios.

Installation & Setup:
  Clone the repository:

  Bash
  [git clone https://github.com/CheSubhro/Rural-Cravings.git](https://github.com/CheSubhro/Rural-Cravings.git)
  cd Rural-Cravings
  Install Dependencies:
  Navigate to individual folders (e.g., Admin Panel/Backend, Website/Frontend) and run:
  
  Bash
  npm install
  Run Development Servers:
  You can use the root-level scripts to run components concurrently:
  
  For Admin Development:
  
  Bash
  npm run admin-dev
  For Website Development:
  
  Bash
  npm run website-dev
