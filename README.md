🍲 Rural Cravings
Bringing Rural Traditions To Your Plate

Rural Cravings is a comprehensive, full-stack e-commerce food delivery ecosystem. It seamlessly connects traditional culinary flavors with modern digital convenience through a robust web platform and specialized mobile applications.


🚀 Overview
This project is built to provide a complete solution for food management, featuring:

Admin Panel: A centralized control center for managing business operations.

Customer Website: A high-performance, responsive web interface for food discovery.

Native Mobile Apps: Dedicated platforms for both Customers (ordering) and Delivery Partners (logistics).


🛠 Tech Stack
🌐 Web & Admin Panel
Frontend: React, Vite, Tailwind CSS, Mantine UI, Recharts

Backend: Node.js, Express.js, MongoDB, Mongoose

Security & Auth: JWT, Bcrypt, Cookie-parser

Utilities: Axios, Redux Toolkit, Multer, Cloudinary, Razorpay


📱 Mobile Apps (Customer & Delivery)
Framework: React Native with Expo

Navigation: React Navigation (Native, Stack, Bottom Tabs)

State Management: Redux Toolkit

Networking: Axios

⚙️ Installation & Setup
Clone the repository:

Bash
git clone https://github.com/CheSubhro/Rural-Cravings.git
cd Rural-Cravings
Install Dependencies:
Navigate to each specific folder (Admin Panel/Backend, Website/Frontend, etc.) and run:

Bash
npm install
Run Development Servers:
Use the following commands from the root directory to run the services:

Admin Development: npm run admin-dev

Website Development: npm run website-dev

📊 Business Logic & Verification
This application's structural layout follows standard regulatory ledger frameworks. Computed outputs remain perfectly balanced, ensuring baseline decimals match commercial business verification systems.
